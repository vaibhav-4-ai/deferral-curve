# Build log

A short record of the decisions I've made while building deferral-curve, and why.

## Decisions

- **Licence:** I have used Apache 2.0, which includes an explicit patent grant: anyone who contributes code also licenses any patents covering it, so nobody can contribute and later sue the people using the project.
- **Where things run:** tests and checks run automatically on GitHub Actions (cloud Linux machines, Ubuntu) every time I
  push. Nothing heavy runs on my own laptop.
